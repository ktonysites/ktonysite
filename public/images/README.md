# Photo assets

The current `tony-portrait.svg` is an illustrated brand frame, not a photograph. When Tony's photos are ready, add optimized WebP files in this folder (for example, `tony-ken-portrait.webp`) and point the hero image in `Home.tsx` to the chosen file. Keep the originals in a separate archive and use descriptive alt text for the final portraits.

Suggested hero portrait: landscape crop, 1600 × 1200 px or larger, WebP, roughly 300 KB or less. The site uses `object-fit: cover`, so a centered head-and-shoulders crop works well.
